# Frontend - Notion Automation

Módulo de frontend para visualização, dashboards e controle das automações da página acadêmica no Notion.

## Estrutura Prevista

- Interfaces web para acompanhamento de tarefas, sincronização e gatilhos de automação.

## Execução

```bash
# Executar a partir da raiz
npm run dev:frontend # quando configurado

# Ou a partir do diretório frontend
cd frontend
npm run dev
```
